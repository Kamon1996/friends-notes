# Друзья (friends-notes)

Мобильное приложение для iOS и Android (React Native + Expo): записная книжка о близких людях с напоминаниями.

## Что умеет

- **Друзья** — имя, аватар-эмодзи, телефон, день рождения (можно без года), предпочтения в еде, любимые цветы, идеи подарков, заметки.
- **Избранные** — звезда в шапке карточки или переключатель в форме; избранные стоят выше остальных в списке друзей, в окне выбора «для кого» и первыми получают большие карточки «Сегодня».
- **Удаление из списка** — свайп строки влево открывает кнопку «Удалить»; долгое нажатие включает режим выбора, как в Telegram: отметить нескольких, добавить их в избранное, выключить уведомления или удалить. Удаление всегда с подтверждением.
- **Умный поиск по имени** — находит «Нинель» по `ninel`, «Юлию» по `Julia`, не путается в ё/е и раскладке («ybytk» → «нинел»): имя и запрос приводятся к общему скелету (`src/lib/search.ts`).
- **Тишина для отдельных людей** — колокольчик в карточке друга, переключатель в форме или иконка в режиме выбора: уведомления о дне рождения и важных датах этого человека не приходят, а напоминания, созданные вручную, остаются.
- **Соцсети** — чипы «значок + название сети» в карточке друга: нажатие открывает профиль, долгое нажатие копирует ссылку. Добавление одним полем «Ссылка или ник»: ссылка узнаётся по домену (каталог на 82 сети в `src/lib/socials.ts`, всё остальное — «Сайт»), по нику сеть выбирается из каталога. При импорте из Telegram ссылки, @ник и подписи вроде «tg: ник», «inst — @ник» из «О себе» становятся соцсетями, остаток текста — заметкой; из контактов телефона берутся поля «Сайт». У каждой сети есть сокращения и русские написания (`aliases`), по ним работают и разбор «О себе», и поиск в списке сетей. Эмблемы сетей — `src/lib/brandGlyphs.ts`, собирается скриптом `scripts/brand-glyphs.js` из пакета simple-icons (CC0), недостающие дорисованы вручную.
- **Важные даты** — годовщины и любые события, с повтором каждый год или однократно.
- **Напоминания** — свайп вправо отмечает сделанным, влево удаляет с подтверждением; долгое нажатие включает режим выбора, чтобы разом отметить, вернуть или удалить несколько; фильтры «Активные», «Сделанные», «Все», «Для себя», «Друзья». Для друга или для себя; однократные (дедлайны, с предупреждением заранее: за час/день/3 дня/неделю) и повторяющиеся: каждый день, неделю, раз в 2 недели, месяц, раз в 2 месяца, год или свой интервал («каждые N дней/недель/месяцев/лет»).
- **Импорт из контактов телефона** — список с поиском и чекбоксами, фильтр «С днём рождения»; переносятся имя, телефон, день рождения (в том числе без года), годовщины и другие даты, заметка (на Android). Уже добавленные люди отмечаются и не дублируются.
- **Поправить на месте** — нажатие на блок «Еда», «Цветы», «Подарки» или «Заметки» в карточке друга открывает шторку с этим полем (`src/components/PrefSheet.tsx`, список блоков — `src/lib/prefs.ts`): клавиатура открыта, курсор в конце текста, «Сохранить» — и карточка обновилась. Закрыть с правками — приложение спросит, сохранить ли; пустой блок исчезает из карточки.
- **Пол друзей** — для поздравлений с 8 Марта и 23 Февраля. Определяется сам, в фоне: вскоре после запуска, при
  возвращении в приложение и когда появились новые или переименованные друзья; нигде не показывается, кроме формы друга.
  Ступени (`src/lib/genderDetect.ts`): 1) своя база имён и правила (`src/lib/gender.ts`, `src/lib/genderNames.ts`) —
  только уверенные случаи: имена, «мама/брат», отчество, «кызы/улы», окончание фамилии рядом с другим словом; Саша, Женя,
  Валя и другие неоднозначные — никогда сами по себе; 2) Genderize.io: только имя и страна по коду номера, ответ
  принимается при вероятности ≥ 0,95 и ≥ 30 людях, до 100 имён за запуск (бесплатный лимит); 3) встроенный ИИ телефона
  (Gemini Nano, модуль `modules/device-ai`, ML Kit GenAI Prompt), если есть; 4) облачный ИИ — модуль `src/lib/ai`
  (только имена, по 25 за вопрос).
  У друга запоминается последняя ступень, которая ответила «не знаю» (`genderStage`), — следующий запуск продолжает со
  следующей, и один сервис про одного человека дважды не спрашивается. Сбой сети ничего не отмечает; лимит или отказ
  сервиса — пауза для всего сервиса (сутки, неделя, час при 5xx). Все ступени не помогли — в форме друга
  «Не удалось определить — выбери сам». Ручной выбор (`genderBy: 'manual'`, в том числе «Не указан») главнее всего и
  автоматикой не меняется. Определённый пол при переименовании остаётся; если определить не удалось — после
  переименования пробуем заново. Из-за ML Kit — Android 8+ (API 26) и
  Kotlin 2.3 (`expo-build-properties`).
- **Модуль ИИ** (`src/lib/ai`) — основа для любых ИИ-задач приложения на бесплатных ключах: Google Gemini,
  OpenRouter, Hugging Face. У каждой задачи свой порядок сервисов (`tasks.ts`: кто лучше справляется — первым).
  Сервис не ответил — спрашиваем следующий; у сервиса несколько моделей (`providers.ts`), убранную или упёршуюся в
  свой лимит заменяет следующая (не больше трёх за вопрос). Лимит, отказ или сбой — сервис или модель на паузе до
  времени, которое назвал сам сервис (`Retry-After`, `X-RateLimit-Reset`, Gemini `RetryInfo` и дневная квота до
  полуночи по тихоокеанскому), иначе — по умолчанию, с каждой неудачей подряд дольше (`limits.ts`); до конца паузы
  его не трогаем, паузы помнятся между запусками. Нет сети — паузы нет. Бесплатные модели OpenRouter берутся из его
  списка (раз в неделю). Ключи — секреты репозитория `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `HF_TOKEN`, подставляются при сборке; нет ключа — сервис пропускается. Ключи лежат внутри APK: используй
  бесплатные тарифы без привязанной карты — тогда в худшем случае кончится лимит, но списаний не будет.
  Для пользователя ИИ — «магия»: в интерфейсе, «Что нового» и политике конфиденциальности сервисы, модели и
  библиотеки не называем (политика говорит о «сторонних сервисах»); это проверяет `src/lib/__tests__/magic.test.ts`.
- **Знак зодиака** — чип рядом с отсчётом до дня рождения в карточке друга (`src/components/ZodiacGlyph.tsx`, расчёт —
  `src/lib/zodiac.ts`): знаки нарисованы линией в стиле иконок приложения, цвет — по стихии из акцентов приложения
  (огонь — терракота, земля — эвкалипт, воздух — мёд, вода — индиго). Есть и у дня рождения без года. В списке друзей и в
  карточке «Сегодня» — маленький знак нейтральным цветом. Настройки → «Оформление» → «Знаки зодиака» (по умолчанию включено).
- **Резервная копия** (настройки → «Резервная копия»): «Сохранить копию» собирает друзей, даты, напоминания, настройки и фото
  (ужатые до 360 точек JPEG, в том числе фото из контактов) в один JSON-файл `druzya-kopiya-ГГГГ-ММ-ДД.json` и открывает
  «Поделиться»; «Восстановить из копии» выбирает файл, показывает, что в нём, и после подтверждения заменяет данные —
  прежние откладываются в хранилище под ключом `…/data/v1.before-restore`. Формат и проверки — `src/lib/backup.ts`
  (чужие и испорченные файлы, пути к файлам из копии не берутся, фото — только картинки разумного размера, имена файлов
  фото — только из букв и цифр), файлы — `src/lib/backupFiles.ts` (+ `.web.ts`). Плюс системное резервное копирование
  Android (`allowBackup`): после него номер календаря «Друзья» может указывать на чужой календарь, поэтому синхронизация
  трогает календарь только с нашим внутренним именем.
- **Шторки** — общий компонент `src/components/Sheet.tsx`: фон плавно темнеет на месте, выезжает только сама шторка (встроенная анимация Modal «slide» тащила снизу весь экран вместе с затемнением). Пока шторка уезжает, содержимое остаётся прежним — компоненты держат последнее показанное. В e2e часы ставятся через `clock.install` (время идёт), иначе анимации, которые меряют время по `Date.now`, не доигрывают.
- **Связь в один тап** — в карточке друга кнопки Позвонить / Telegram / WhatsApp / Viber (только те мессенджеры, где человек есть). Для уже добавленных друзей мессенджеры и фото подтягиваются в настройках по номеру телефона.
- **Аватары** — при импорте берутся из контактов телефона или из Telegram, если фото есть; иначе инициалы. В форме друга фото можно выбрать из галереи, снять на камеру, взять из контактов или убрать: картинка ужимается до двух размеров и хранится в папке приложения (`src/lib/avatars.ts`).
- **Скоро** — лента: просроченное, сегодня, ближайшая неделя, месяц.
- **Локальные уведомления** о днях рождения, важных датах (в день события и за день, время настраивается) и напоминаниях. В уведомлении о дне рождения — возраст и подсказка из заметок (цветы, еда, идеи подарков), а также кнопки «Позвонить» и «Написать». Нажатие на уведомление открывает нужный экран.
- **Что нового** — список изменений по версиям лежит в приложении (`src/lib/changelog.ts`). После обновления при первом запуске шторка показывает изменения версий, которых пользователь ещё не видел (новая установка ничего не показывает); полная история и номер версии — в настройках, раздел «Помощь». При смене `expo.version` в `app.json` добавь запись сверху — тест `changelog.test.ts` не даст забыть.
- **Отчёты о сбоях** — автоматически через Sentry (`src/lib/crashReports.ts`): стек ошибки, версия и модель телефона, без данных людей; переключатель в настройках. DSN проекта лежит в `app.json` (`extra.sentry.dsn`, это публичный ключ клиента; секрет `SENTRY_DSN` при сборке его переопределяет), sourcemaps загружаются при наличии `SENTRY_AUTH_TOKEN`, без него сборка идёт, а загрузка пропускается. Проверка: пять быстрых нажатий на строку версии внизу настроек отправляют тестовое событие в Sentry. «Сообщить о проблеме» открывает чат с разработчиком в Telegram с готовой шапкой: версия, система, модель, номер последнего сбоя (`src/lib/bugReport.ts`).
- Данные хранятся только на телефоне (AsyncStorage), сервер не нужен; наружу уходят только отчёты о сбоях, если они включены.
  При чтении данные старых версий приводятся к текущему виду (`src/lib/storage.ts`). Если сохранённое не разобрать,
  оно откладывается в резервную копию рядом, а не затирается; если хранилище не прочиталось, приложение ничего
  не записывает до следующего запуска.
- Даты и время в формах не сохраняются молча с ошибкой: пока в поле «31.02» или «25:99», форма подсказывает, что
  поправить, и не сохраняется. Ссылки соцсетей и сайтов принимаются и открываются только с http и https.
- **Календарь телефона** (настройки → «Календарь», только Android): приложение заводит в системной базе календарей
  свой локальный календарь «Друзья» и держит в нём дни рождения и важные даты (план событий и дубли —
  `src/lib/calendarPlan.ts`, синхронизация — `src/lib/calendarSync.ts`, доступ к календарю, контактам и хранилищу —
  `src/lib/deviceCalendar.ts`). Его показывают Samsung Календарь и Google Календарь на этом телефоне; с облаком он не
  синхронизируется. Каждая годовщина — отдельное событие на весь день на прошлый, этот и два следующих года,
  с возрастом в названии («🎂 Аня Смирнова · 31 год»), без напоминаний; с Новым годом окно сдвигается.
  При запуске и возвращении в приложение события сверяются с календарём: удалённые вручную возвращаются, свои потерянные
  (сбой посреди записи) удаляются, события, добавленные в календарь «Друзья» вручную (без подписи приложения), не
  трогаются; скрытый календарь Android не отдаёт в списке, поэтому тогда приложение верит сохранённому. Под
  переключателем — итог: сколько событий и что не повторено; нет доступа — кнопка «Разрешить доступ».
  Дублей нет: день рождения друга, записанный в контактах (тот же номер или имя и тот же день), телефон показывает
  сам, а событие в другом видимом календаре в тот же день с его именем и словами «день рождения» (или названием
  важной даты) тоже считается тем же. Контакты читаются, только если доступ уже дан; названия и даты чужих событий
  только сравниваются в памяти. Там же «Выгрузить даты» — `.ics` со всеми датами
  (`src/lib/ics.ts`) для импорта в Google Календарь на сайте или в любой другой календарь.
- Ссылка на соцсеть или WhatsApp открывается сразу в приложении, если оно установлено: сначала в официальном
  приложении этой сети (пакеты — `src/lib/appLinks.ts`), затем в любом не-браузерном, и только потом в браузере.
  Это делает локальный модуль `modules/open-in-app`; пакеты объявлены в его манифесте (`<queries>`), иначе Android 11+
  их не видит — совпадение списков проверяет юнит-тест.

## Импорт и скорость

Телефонная книга на Android читается одним запросом к таблице `data` через модуль `contacts-raw` (имена, номера, даты,
заметки, строки мессенджеров) плюс фото: 10 тысяч контактов — доли секунды, тогда как expo-contacts собирает каждый
контакт отдельно (он остаётся запасным путём). Прочитанная книга кэшируется в памяти (`src/lib/contactsCache.ts`):
при запуске, если доступ уже дан, читается в фоне, экран импорта показывает её сразу и дочитывает свежую версию
в фоне; кнопка «Перечитать» в шапке — принудительно. Результат импорта из Telegram хранит нативный модуль до выбора.
Все длинные списки (лента, друзья, напоминания, импорт, выбор друга) — виртуализированные `FlatList`.

## Дизайн

Система «Тёплый альбом»: бумага, чернила и один акцентный цвет. Имена и заголовки — шрифт Lora, интерфейс — Golos Text
(оба грузятся через `expo-font` из пакетов `@expo-google-fonts/*`). Аватар — фото из контактов, а без него инициалы
на одном из шести тёплых оттенков, выбранном по имени.

- Токены и палитры: `src/lib/theme.ts`; провайдер темы и стили компонентов: `src/lib/themeContext.tsx`.
- Светлая и тёмная тема (по умолчанию как в системе); **акцентный цвет выбирается отдельно для светлой и тёмной
  темы** — шесть вариантов (терракота по умолчанию, мёд, эвкалипт, слива, индиго, малина). У всех белый текст
  на кнопках держит контраст не ниже 4.5:1. Выбор живёт на экране «Оформление» (настройки → «Тема и цвет»): сверху
  живой фрагмент «Скоро» из настоящих компонентов в выбранных цветах (`src/components/ThemePreview.tsx`, поддерево
  в другой теме даёт `ThemeScope` из `themeContext`), нажатие на цвет перекрашивает его.
- Иконки — свои, одной линией (`src/components/Icon.tsx`), без эмодзи.
- Логотип — «узелок на память»: сердце из одной ленты, завязанной узлом, на градиенте «закат» (терракота → малина).
  Исходник знака: `assets/logo/knot.svg`, иконка целиком: `assets/logo/icon.svg`. Из них собраны `assets/icon.png`,
  адаптивная иконка Android (передний план, фон, монохром), заставка (`splash-icon.png`, градиентная лента на бумаге
  или тёмном фоне), иконка уведомлений и фавикон.

## Импорт из Telegram (Android)

Импорт из Telegram — всегда через вход в свой аккаунт: он даёт дни рождения, фото и @username. Имена и номера,
которые Telegram, WhatsApp и Viber кладут в телефонную книгу, и так попадают через обычный импорт контактов.
Экран устроен как мастер из трёх шагов (Вход → Загрузка → Выбор) с индикатором сверху: до входа — что получишь и
на каких условиях, честный рассказ про доступ живёт в шторке «Что получает приложение», на шаге загрузки — кольцо
прогресса и счётчики запросов (сообщений и чатов всегда 0). В веб-превью шаги можно посмотреть без Android:
`localStorage['friends-notes/tg-preview'] = 'phone' | 'qr' | 'code' | 'loading' | 'done'`.

Telegram не поддерживает ограниченный доступ, поэтому приложение честно предупреждает об этом, читает только
контакты и профили (в модуле нет функций для сообщений, чатов и файлов), показывает счётчики запросов и сразу выходит
из аккаунта. Сессия видна в Telegram → Устройства как «Друзья · импорт контактов».

Войти можно по номеру с кодом или **по QR-коду** со второго устройства с Telegram (Настройки → Устройства →
сканировать QR) — тогда код и пароль в приложение вводить не нужно; на том же телефоне QR отсканировать нельзя.

Загрузка идёт в нативном модуле в фоне с foreground-уведомлением — можно свернуть приложение или переключать вкладки;
прогресс виден в уведомлении и на плашке внизу экрана.

Вход в свой аккаунт Telegram прямо в приложении (номер → код → облачный пароль), загрузка контактов
с днями рождения и «о себе», затем автоматический выход — сессия не сохраняется. Используется официальная
библиотека [TDLib](https://github.com/tdlib/td), собранная из исходников в GitHub Actions
(`.github/workflows/tdlib-android.yml`, сведения о сборке — `modules/telegram/android/TDLIB_BUILD.md`).
Нужны секреты репозитория `TG_API_ID` и `TG_API_HASH` (my.telegram.org → API development tools);
в конфиг приложения они подставляются только в момент сборки.

## Запуск

```bash
npm install
npx expo start          # QR-код → открыть в Expo Go на телефоне
npx expo start --web    # превью в браузере (без уведомлений)
```

Проверки:

```bash
npm run typecheck
npm run lint
npm test        # юнит-тесты логики: даты, лента, уведомления, поиск, импорт, соцсети
npm run e2e     # сквозные сценарии на веб-сборке (один раз: npx playwright install chromium)
npm run e2e -- --grep импорт   # только сценарии, в названии которых есть слово
```

Как устроены тесты:

- **Юнит-тесты** (`src/lib/__tests__`, `node:test` через `tsx`) проверяют чистую логику без интерфейса: даты и годовщины,
  ленту «Скоро», перенос повторяющихся напоминаний, расписание уведомлений, поиск, разбор соцсетей, импорт контактов и Telegram.
- **Сквозные сценарии** (`scripts/e2e-web.js`, Playwright) проходят приложение как человек: нажатия, поля, долгие нажатия,
  и проверяют и экран, и сохранённые данные. Каждый сценарий идёт в чистом браузере со своими данными и замороженными
  часами (среда, 10 июня 2026, 12:00 по Москве), поэтому сценарии независимы и одинаково проходят в любой день.
  Снимки упавших сценариев — в `e2e-results/`.
- **Известные ошибки** записаны как обычные тесты с пометкой: `{ todo: '…' }` в юнит-тестах и `{ known: '…' }` в сквозных.
  Пока ошибка есть, тест виден в отчёте и не валит прогон. Когда ошибку исправят, тест начнёт проходить: юнит-тест
  покажется как пройденный `todo`, а сквозной прогон упадёт с «FIXED», чтобы пометку сняли.
- Что в браузере не проверить и остаётся ручной проверкой на телефоне: свайпы, системные окна, вход в Telegram,
  контакты телефона, уведомления, календарь выбора даты, фото, крупный системный шрифт.
- В GitHub Actions на каждый пуш работает **Tests**: типы, линтер, юнит-тесты, веб-сборка и сквозные сценарии
  (около 5 минут); при сбое снимки прикладываются к запуску.

## Сборка APK без компьютера (GitHub Actions)

1. Создай токен на https://expo.dev/settings/access-tokens.
2. Добавь его в репозиторий: **Settings → Secrets and variables → Actions → New repository secret**, имя `EXPO_TOKEN`
   (нужен для подписи: ключ хранится в EAS, и локальная сборка берёт его оттуда же).
3. Сделай коммит со словом `[apk]` в сообщении или запусти workflow **Android APK** вручную (Actions → Run workflow).
   Сборка идёт прямо на машине GitHub (`eas build --local`), квота EAS не тратится. Минут через 20–30
   готовый APK появится в разделе **Releases** репозитория, прямая ссылка на файл есть и в итогах запуска.
4. Слово `[apk-cloud]` в сообщении коммита (или режим `cloud` при ручном запуске) собирает по-старому, на серверах EAS:
   ссылка на сборку будет на expo.dev. На бесплатном плане таких сборок ограниченное число в месяц.

## Сборка вручную

Через EAS (облачная сборка, Xcode/Android Studio не нужны):

```bash
npx eas-cli@latest build --platform android --profile preview   # APK для установки
npx eas-cli@latest build --platform ios
```

## Устройство кода

```
src/app/            экраны (Expo Router)
  (tabs)/           вкладки: Скоро, Друзья, Напоминания
  friend/[id].tsx   карточка друга
  friend/edit.tsx   создание/редактирование друга
  reminder/edit.tsx создание/редактирование напоминания
  settings.tsx      настройки уведомлений, оформления, «Что нового»
  whats-new.tsx     история изменений по версиям
src/lib/
  types.ts          модель данных
  changelog.ts      список изменений по версиям
  socials.ts        каталог соцсетей, разбор ссылок и «О себе»
  dates.ts          работа с датами, склонения
  events.ts         лента «Скоро» и расчёт расписания уведомлений
  notifications.ts  планирование локальных уведомлений
  store.tsx         состояние + сохранение на устройстве
src/components/     UI-компоненты
```

iOS позволяет держать не больше 64 запланированных уведомлений, поэтому приложение
планирует ближайшие 60 и пересчитывает расписание при каждом изменении и открытии.
