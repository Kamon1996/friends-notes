# Публикация в магазинах

Материалы для витрин и чек-листы по каждому магазину. Скриншоты лежат в `screenshots/` (1080×1920), баннер — `feature-graphic.png` (1024×500),
политика конфиденциальности — `docs/privacy.html` (нужно опубликовать по публичному адресу, см. ниже).

## Сборка для магазинов

- **Google Play** принимает только Android App Bundle: коммит со словом `[aab]` в первой строке сообщения (или Run workflow → режим `aab`) кладёт
  `friends-notes-<версия>.aab` в Releases. Подпись — ключ из EAS; при первой загрузке Play сам включит Play App Signing и
  примет его как ключ загрузки.
- **RuStore, Samsung Galaxy Store, Huawei AppGallery** принимают APK: тот же файл, что в Releases после `[apk]`.
- Версия (`expo.version` в `app.json`) видна пользователю; `versionCode` считает EAS (`appVersionSource: remote`) и
  увеличивает при каждой production-сборке. Магазины требуют, чтобы `versionCode` рос от загрузки к загрузке.
- Вместе с версией обновляй `src/lib/changelog.ts`: первая запись должна совпадать с `expo.version` (тест это проверяет),
  её пункты пользователь увидит в шторке «Что нового» после обновления. Тот же текст подойдёт для поля
  «Что нового в версии» в консоли магазина.

## Политика конфиденциальности

Текст в `docs/privacy.html` (русский и английский). Магазины требуют публичную ссылку. Самый простой путь:
GitHub Pages → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
Адрес будет `https://kamon1996.github.io/friends-notes/privacy.html`. В файле два места `[EMAIL РАЗРАБОТЧИКА]` /
`[DEVELOPER EMAIL]` — впиши контактную почту.

## Google Play · анкета «Безопасность данных»

Опорная позиция: приложение ничего не передаёт разработчику. Единственная передача наружу — вход пользователя
в его собственный аккаунт Telegram при импорте (номер телефона и код подтверждения уходят серверам Telegram
по MTProto, зашифровано). Контакты, фото, заметки и напоминания обрабатываются только на устройстве.

Рекомендуемые ответы:
- Собирает ли приложение данные: **да** (номер телефона при входе в Telegram), **необязательно**, цель «Функции
  приложения», **не передаётся другим третьим лицам** помимо самого сервиса Telegram, **шифруется при передаче**,
  **пользователь может удалить** (данные входа стираются при выходе, который происходит сразу после импорта).
- Контакты, фото, имена, даты: **не собираются** (обработка только на устройстве, вне устройства не передаются).
- **Отчёты о сбоях (диагностика): собираются**, автоматически, через Sentry; **необязательно** (выключается в
  настройках); цель «Функции приложения» / «Аналитика сбоев»; **передаются третьей стороне** (Sentry);
  **шифруются при передаче**; без личных данных. В RuStore это тип данных «Отчёты об ошибках» и «Диагностика».
- Нет аналитики поведения, рекламы, идентификаторов устройства, местоположения.
- Резервная копия: файл создаётся на устройстве и уходит только туда, куда пользователь сам его отправит через «Поделиться»;
  резервное копирование Android (`allowBackup`, по умолчанию включено) идёт в аккаунт Google пользователя силами системы.
  Ни то ни другое не считается сбором данных разработчиком. Данные TDLib лежат в `noBackupFilesDir` и в копию не попадают.
- Независимая проверка безопасности: нет.

Разрешения в сборке печатаются в итогах каждого запуска `[apk]` (раздел «Разрешения в APK»): сверь с анкетой.
Ожидаемый набор: `READ_CONTACTS`, `READ_CALENDAR`, `WRITE_CALENDAR`, `INTERNET`, `POST_NOTIFICATIONS`, `VIBRATE`,
`READ/WRITE_EXTERNAL_STORAGE` (только до Android 12, для фото), без `SYSTEM_ALERT_WINDOW` и без точных будильников.
Календарь — по желанию: приложение заводит свой локальный календарь «Друзья» с днями рождения, а чтобы не дублировать,
сравнивает на устройстве названия и даты событий других календарей; данные не покидают телефон и не сохраняются, поэтому
в анкете безопасности данных календарь не указывается как собираемые данные.

## RuStore: первый магазин, пошагово

1. Регистрация: https://console.rustore.ru → «Стать разработчиком». Бесплатно; физлицу нужны паспортные данные
   (для РФ — ИНН/СНИЛС). Если из твоей страны регистрация физлицом недоступна, следующий по простоте — Huawei AppGallery.
2. «Создать приложение»: название «Друзья», категория «Образ жизни», возраст 0+, язык русский.
3. Загрузить APK из Releases (`friends-notes-<версия>.apk`). Пакет `com.kamon1996.friendsnotes`, подпись EAS,
   `versionCode` растёт автоматически с каждой сборкой.
4. Витрина: краткое и полное описание из этого файла, иконка `icon-512.png`, скриншоты из `screenshots/`
   (минимум два, лучше все семь).
5. Политика конфиденциальности: публичная ссылка. Пока репозиторий приватный, GitHub Pages не работает — используй
   страницу https://claude.ai/artifact/AeeE2bJjnPm5wRgadBXvy8 (открой её, Share → доступ по ссылке) или сделай
   репозиторий публичным и включи Pages из папки `docs`.
6. Контактная почта поддержки — обязательное поле.
7. Отправить на модерацию: обычно 1–3 дня. Проверяют запуск без падений, соответствие описанию, объяснение
   разрешений (у нас: контакты — только для импорта, уведомления — напоминания, календарь — свой календарь
   «Друзья» с днями рождения, если включить его в настройках).

## Чек-листы по магазинам

**Google Play (play.google.com/console)**
1. Аккаунт разработчика: 25 $ разово, подтверждение личности.
2. Для новых личных аккаунтов — закрытое тестирование: 12 тестировщиков, 14 дней подряд, потом доступ к продакшену.
3. Создать приложение → загрузить AAB → заполнить: описание, скриншоты (минимум 2), баннер 1024×500, иконка 512×512
   (`assets/icon.png`, ужать), политика конфиденциальности (ссылка), анкета IARC, «Безопасность данных», целевая аудитория.
4. Объявить разрешение `READ_CONTACTS` через форму «Доступ к контактам» не нужно (это не SMS/Call Log), но в описании
   стоит объяснить, зачем оно: импорт друзей.

**RuStore (console.rustore.ru)**
1. Регистрация бесплатная; нужен ИНН/паспортные данные для физлица.
2. Загрузить APK, заполнить описание, скриншоты (можно те же), возраст 0+, ссылку на политику.
3. Модерация обычно 1–3 дня.

**Samsung Galaxy Store (seller.samsungapps.com)**
1. Аккаунт продавца бесплатный, нужно подтверждение.
2. APK, описание, скриншоты, рейтинг, политика. Указать совместимые устройства Galaxy.

**Huawei AppGallery (developer.huawei.com)**
1. Аккаунт разработчика, проверка личности.
2. Приложение не использует Google Play Services, поэтому работает на устройствах без них без доработок.
3. APK или AAB, описание, скриншоты, политика, возрастной рейтинг.
